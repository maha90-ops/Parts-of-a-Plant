# 🌱 مَهَمَّةُ إِنْقَاذِ لُولُو

بيئة تعلّم **تكيفية تفاعلية** لدرس «أجزاء النبات ووظائفها» للمرحلة الأساسية، بهوية بصرية فلسطينية
(التطريز الفلسطيني، وشجر الزيتون، وشقائق النعمان، والكوفية، وألوان العلم).

## التشغيل
لا يحتاج المشروع إلى أي تثبيت أو مكتبات خارجية (HTML + CSS + JavaScript فقط).
```bash
python3 -m http.server 8765
```
ثم افتح `http://localhost:8765/`. (يعمل أيضًا بفتح `index.html` مباشرة في المتصفح.)

## رحلة الطالب
الرئيسية ← التعريف بالمهمة ← مهمة اكتشاف المستوى (٨ مهارات) ← الملف الذكي واختيار المسار ← الخريطة
← مدينة الجذور ← طريق الساق ← مصنع الأوراق ← حديقة الأزهار ← المختبر النباتي ← مركز إنقاذ لولو
← التقييم النهائي ← التقرير ← الشهادة.

## كيف يعمل التكيف (`js/adaptive-engine.js`)
| الآلية | التفاصيل |
|---|---|
| درجة الاستحقاق | كل استجابة تُحوَّل إلى قيمة بين ٠ و١ تُخصم منها المحاولات (−٠٫٣) والتلميحات (−٠٫١٥) والبطء الشديد |
| الإتقان | تحديث بايزي مبسّط (BKT) لكل مهارة ولكل جزء، بمعاملات تخمين/زلل حسب الصعوبة؛ الخطأ المتسرّع (أقل من ٢٫٥ ث) يؤثر أقل |
| اختيار المسار | ٨٠+ متقدم، ٦٠–٧٩ متوسط، أقل من ٦٠ علاجي، **ثم** يُعدَّل حسب معدل التلميحات والمحاولات والمفاهيم الخاطئة والوقت، مع ذكر الأسباب |
| سلّم الدعم | خطأ ١: تلميح ← خطأ ٢: تلميح أوضح ← خطأ ٣: شرح مصغّر ← نشاط علاجي ← إعادة المحاولة (المتقدم: تشجيع أولًا ثم تلميح) |
| الصعوبة | ترتفع بعد إجابتين ممتازتين متتاليتين، وتنخفض بعد التعثر؛ وتُعرض أنشطة إثرائية عند الإتقان المتكرر |
| إعادة التقييم | بعد كل منطقة قد يتغير المسار خطوة واحدة صعودًا أو هبوطًا |
| تحليل الأخطاء | لكل خيار خاطئ نوع خطأ (خلط أجزاء، خلط وظائف، مفهوم خاطئ…) وتُسجَّل علامات ضعف مثل `root_function_matching` |
| التوصيات | نشاط علاجي أو تدريب موجّه أو نشاط إثرائي، حسب أضعف مهارة وأضعف جزء |

## الإصدار ٤: «مهمة إنقاذ لولو – مغامرة في عالم النبات» (الصف الثالث)
- **لولو شخصية رئيسية:** تتكلم بفقاعات قصيرة في كل محطة، وتتغيّر تعابيرها (سعيدة، متفاجئة، حزينة، تحتاج المساعدة، سعيدة جدًا).
- **الصفحة الرئيسية:** قصة قصيرة تظهر سطرًا بعد سطر، ثم «🚀 ابدأ مهمة الإنقاذ».
- **موقف افتتاحي لكل محطة:** مثل «لولو عطشانة! 💧» مع سؤال، ثم حركة بصرية للنتيجة (الماء من التربة إلى الجذر…).
- **نشاط «سمِّ أجزاء لولو»:** سحب وإفلات، مع بديل بالنقر.
- **مسار الماء:** التربة ← الجذر ← الساق ← الأوراق، مع تلميح خاص بكل خطوة: «اقتربت! 💡 فكّر…».
- **«مختبر العالم الصغير»:** أربع تجارب: بلا ماء، وبلا ضوء، وجذر متوقف، ورحلة الماء. كل تجربة بتسلسل 🔮 توقّع ← 🧪 جرّب ← 👀 شاهد ← 💡 فسّر.
- **مستويات التفكير الخمسة:** تظهر على كل سؤال: التعرف، والمطابقة، والتفسير، والاستنتاج، وحل المشكلة.
- **التغذية الراجعة الإيجابية:** «💡 فكّر مرة أخرى…» ثم «🌱 تذكّر…» ثم شرح بصري ونشاط علاجي. وعند رفع الصعوبة: «ممتاز! يبدو أنك مستعد لتحدٍّ أكبر!».
- **خريطة المغامرة:** نقطة «🌱 البداية»، وشريط «أنجزتَ … من ٦ محطات»، و«✅ تم الإنجاز» على المحطات المكتملة.
- **🌱 جواز سفر عالم النبات:** ختم لكل محطة، ولقب «🏆 عالم نبات صغير» عند اكتمال الأختام.
- **مركز الإنقاذ:** «🚨 إنذار! لولو ما زالت تحتاج إلى مساعدتك!»، ثم أدلة (💧 🌱 🌿 🍃 ☀️) وسلسلة قرارات. وأثناء الشفاء تظهر سلسلة الفهم: «الجذر يمتص ← الساق ينقل ← الأوراق تصنع الغذاء».
- **الوصول:** وضع ألوان مناسب لعمى الألوان، وشرح صوتي اختياري، وقراءة آلية اختيارية، ومؤثرات صوتية اختيارية.
- **الصوت:** مجلد `audio/` جاهز لتسجيلات بشرية، وتعليماته في `audio/README.md`.
- **لوحة المعلم:** نسبة الإنجاز، والمحطات المكتملة، والأسئلة التي أخطأ فيها الطالب، والمهارات المتقنة، والمهارات التي تحتاج إلى دعم، ومستوى الطالب.

## نشاطا التحفيز المرتبطان بالأداء
- **🧩 تحدّي البازل: قبة الصخرة في خمس محطات** (`js/puzzle.js`):
  - لكل محطة (الجذر، الساق، الأوراق، الزهرة، المختبر) لوحة لقبة الصخرة في وقت مختلف من اليوم: فجر، صباح، ظهيرة، غروب، ليل.
  - **عدد القطع = عدد أسئلة المحطة** في مسار الطالب: ٦ في المسارين العلاجي والمتوسط، و٨ في المتقدم. وللمختبر ٨ أو ١٠ أو ١٢.
  - كل إجابة صحيحة تضع قطعة، واللوحة ظاهرة بجانب السؤال طوال المحطة.
  - إكمال اللوحات الخمس يمنح شارة «بنّاء قبة الصخرة».
- **⛺ تحدّي الخيمة والزيتون** (`js/village.js`) في مركز إنقاذ لولو:
  - عشر خيام لعشرة أسئلة: الأدلة، والمشكلة، والجزء، والحل، وأسئلة التقييم النهائي الستة.
  - الإجابة الصحيحة من المحاولة الأولى تبني بيتًا وتُسقط حبة زيتون على الكوفية، والصحيحة بعد محاولة أو تلميح تبني بيتًا، والخاطئة تُبقي الخيمة.
  - عند اكتمال البيوت العشرة يرتفع العلم.

## الشهادة PDF
في صفحة الشهادة زر «⬇️ تنزيل الشهادة (PDF)». يلتقط الموقع الشهادة كما تظهر على الشاشة، ويضعها في صفحة A4، وينزّلها باسم الطالب.
المكتبتان المستخدمتان (html2canvas وjsPDF، بترخيص MIT) مضمّنتان في `assets/vendor`، وتُحمَّلان فقط عند الضغط على الزر.
إن تعذّر ذلك تُفتح نافذة الطباعة بديلًا.

## حفظ البيانات
`localStorage` بالمفتاح `plantRescue.v1`. بنية `studentProfile` تشمل: studentId، وname، وdiagnosticResults،
وskillMastery، وpartMastery، وcurrentPath، وcurrentLevel، وactivitiesCompleted، وresponses، وmistakes، وhintsUsed،
وpoints، وseeds، وdrops، وstars، وbadges، وzones، وprogress، وpathHistory، وdecisions، وrecommendations.
للربط بقاعدة بيانات: استبدل `LocalStorageAdapter` في `student-progress.js` بمحوّل يستدعي واجهة API (يوجد مثال في التعليقات).

## إتاحة الوصول (UDL)
قراءة صوتية (Web Speech) مع نص مكتوب دائمًا، وتباين مرتفع، وتكبير النص، وإيقاف الحركات، وتباعد مريح للقراءة،
والتحكم في مستوى الصوت، ودعم كامل للوحة المفاتيح (بما فيه بديل للسحب والإفلات)، وعلامات ✓/✗ ونقوش
لا تعتمد على اللون وحده، واتجاه RTL، والأرقام العربية الشرقية.

## الاختبارات
```bash
node tests/engine.test.js
```
```bash
python3 -m http.server 8765 & node tests/e2e.js
```

## لوحة المعلم
تعرض الطلاب الحقيقيين على الجهاز، إضافة إلى صف تجريبي (١٠ طلاب) يمكن إخفاؤه. تشمل المؤشرات،
ومتوسط كل مهارة، والمهارة الأضعف، والأخطاء الشائعة، وقوائم التدخل العلاجي والمتقدمين، وملف كل طالب،
والتصدير بصيغتي CSV وJSON.
